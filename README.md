## ch32v307vct6 camera
# description
    This project uses a WCH CH32V307VCT6 chip to transmit real-time video to a PC. The camera module is an OV2640, and local video display is achieved via a 128x160 RGB LCD driven by an ST7735S chip.

## Note 
  Only the Ld and User files are included in this repository. Other files, such as the Core folder, need to be configured in the project by yourself.
